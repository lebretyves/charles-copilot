# Terrains patients

Sous-dossiers documentaires pour les terrains de patients a fort impact
perioperatoire. Chaque dossier vise a repondre a trois questions:

1. Quelles variables doivent exister dans la KB pour decrire le terrain ?
2. Quels signaux live doivent modifier les seuils ou la priorite d'alerte ?
3. Quelles donnees sont encore absentes pour construire un score robuste ?
