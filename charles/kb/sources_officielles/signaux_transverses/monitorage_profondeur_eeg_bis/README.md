# Monitorage De Profondeur EEG / BIS

Ce dossier sert a documenter un **signal transversal** utile a plusieurs
complications, sans en faire artificiellement une complication autonome.

Il est surtout utile pour :
- distinguer une hypotension de surprofondeur hypnotique d'une autre cause
- documenter le role du monitorage EEG traite dans le sur- et sous-dosage
- preparer plus tard une complication ou famille de complications de profondeur

Le contenu reste separe des complications respiratoires ou hemodynamiques :
le BIS/EEG traite est ici un **contexte de lecture**, pas un detecteur universel.
