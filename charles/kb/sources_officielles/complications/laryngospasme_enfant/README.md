## Ce que la base source permet deja

- l'IVAS recente augmente les complications respiratoires
- l'intubation tracheale est plus a risque que des dispositifs moins stimulants
- le terrain pediatrique desature vite

## Signaux utiles pour algo

- absence d'EtCO2 efficace
- efforts ventilatoires sans echanges
- desaturation rapide
- contexte extubation / stimulation / aspiration / IVAS recente
