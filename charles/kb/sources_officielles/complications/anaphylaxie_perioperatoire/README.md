- `id`: `anaphylaxie_perioperatoire`
- `niveau_source`: `normatif_plus_pratique_plus_pedagogique`

## Signaux utiles pour algo

- hypotension brutale
- tachycardie ou collapsus
- bronchospasme / Ppeak en hausse
- EtCO2 qui chute
- desaturation
- chronologie apres exposition a un agent declencheur

## Regles candidates

- facteur `debut_brusque` fort
- facteur `hemodynamique + respiratoire` simultanes
- facteur contexte `curare / antibiotique / latex recents`
- facteur peau/muqueuses si observation manuelle disponible

## Combinaisons pertinentes

- hypotension + bronchospasme
- hypotension + EtCO2 en baisse rapide
- tachycardie + hypoxemie + resistance ventilatoire

## Pistes KB

- score `anaphylaxie_probable`
- ordre de preuves: temporalite, composante hemodynamique, composante respiratoire, contexte medicamenteux
